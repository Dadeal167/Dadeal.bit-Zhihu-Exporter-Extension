## 二、商店文案（可直接复制粘贴）

**名称**（≤45 字符 ✓）
```
Dadealbit 知乎文章提取器
```

**简短描述**（≤132 字符）
```
一键把知乎文章/回答提取为 Markdown、HTML、PDF 并打包 zip（含图片与数学公式）
```

**详细描述**
```
Dadealbit 知乎文章提取器是一款轻量的内容导出工具。

• 打开任意知乎文章或回答，一键打包成 zip：Markdown + HTML + PDF（静默生成）+ 原图 + 数学公式
• 数学公式：Markdown 还原为 LaTeX；HTML 内嵌 MathJax 离线渲染；PDF 生成前等待公式渲染完成
• 图片：自动下载原图打包进 zip，相对路径引用，解压即看
• 批量提取：粘贴多个链接（每行一个），自动开标签页逐个打包，完成后自动关闭
• 进度浮窗 + 完成系统通知，点击通知直达下载文件夹
• 知乎页面左下角浮动按钮，一键唤起

隐私说明：本扩展完全本地运行，不收集、不上传任何用户数据。
```

**类别**：`生产力 / Productivity`

**权限说明**（商店如要求"权限理由"，按此填写）：
- `downloads`：保存打包好的 zip 文件
- `storage`：记住用户勾选的导出格式
- `tabs`：批量提取时自动打开/关闭标签页
- `debugger`：调用浏览器打印引擎静默生成 PDF（不弹"另存为 PDF"对话框）
- `offscreen`：在隐藏页面完成 zip 打包与 Blob 下载（浏览器后台线程限制）
- `notifications`：提取完成后发送系统通知
- 知乎域名权限：读取文章内容、下载正文图片

## 四、上传步骤（需要你本人操作，我用不了你的微软账号）

1. 打开 **https://partner.microsoft.com/dashboard/microsoftedge/** （中文：Microsoft 合作伙伴中心）
2. 用**微软账号**登录（没有就注册一个；Edge 扩展开发者注册**免费**，不像 Chrome 商店要 5 美元）
3. 按提示完成开发者账户注册
4. 左侧「**Microsoft Edge → 扩展**」→「**创建新扩展**」
5. 上传 `store/Dadealbit_ZhihuExporter_edge_store.zip`
6. 填写商品页信息：
   - 语言选「简体中文」
   - 粘贴上面的名称/简介/详细描述
   - 类别：生产力
   - 上传徽标 `store/logo_300.png`（宣传图和截图**可不传**，官方为可选项）
7. （如需）填写隐私政策 URL
8. 提交审核 → 认证一般 **1~7 个工作日** 出结果 → 通过后发布

## 五、风险提示（提前知道，别被驳回时懵）

1. **`debugger` 权限**可能触发额外人工审核。若被询问，理由就写"用于调用浏览器打印引擎静默生成 PDF，不用于调试其他页面"。
2. 名称里的"**知乎**"是第三方商标，审核有被要求改名的可能。若被驳回改名，可换「Dadealbit 文章导出助手」之类的名称再提交。
3. 每次更新代码需在 manifest 里升版本号再重新打包上传。
